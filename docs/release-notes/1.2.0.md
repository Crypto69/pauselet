## What's new in 1.2.0

**Repeat on a fixed timetable.** A repeating reminder can now start at a set
time instead of counting from when you last saw it. Under Repeating, turn on
"Start at a set time", pick the time and the days, and optionally an end time:
every 50 minutes from 05:40, Monday to Friday, until 13:00, fires at 05:40,
06:30, 07:20 and so on, the same every day. If your computer was asleep at one
of the times, the reminder still comes on waking as long as less than half the
interval has passed; otherwise it waits for the next time. The editor tells
you when some of the times fall inside quiet hours and will be skipped.

**A warning before a Critical reminder takes over.** A Critical reminder can
now warn you before it blanks the screen, any number of minutes ahead from one
minute up. Turn on "Warn me before it takes over" in the reminder's editor
and set the minutes (on Windows, type the minutes into "Warn before it takes
over"). At the warning time a card says which reminder is coming and when it takes
over, and it stays on screen until you click its tick. Ticking it only closes
the card; the takeover still comes at its time. On iPhone the warning is a
time-sensitive notification. To keep it on screen until you dismiss it, set
Pauselet's banner style to Persistent in iOS Settings → Notifications.

**Windows — reminders keep time after hibernate.** Pauselet now restarts its
timer when the computer wakes or is unlocked, and checks every few seconds
that it is still running, so reminders no longer arrive late after a
hibernate.

**iPhone — roomier Start buttons.** The Start and Start All buttons on an
exercise takeover now have the same padding as Done and Snooze.

The new features are the same on macOS, iPhone and Windows.
