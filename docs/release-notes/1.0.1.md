## What's new in 1.0.1

**Windows — turn reminders on and off from Settings.** The Enabled column in
Settings → Reminders showed On or Off but could not be changed, so the only
way to switch a reminder off was a small checkbox in the tray panel that is
easy to miss. The column is now a checkbox: untick it to turn a reminder off
without deleting it, tick it to turn it back on. The checkbox in the tray
panel (left-click the tray icon) still works too.

macOS and iPhone have no changes in this release apart from the version
number.
